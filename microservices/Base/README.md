\# Pixmind Microservice (Plantilla)



Usa esta plantilla para crear un nuevo microservicio FastAPI para Hugging Face.



\## Cómo usar



1\. Copia esta carpeta

2\. Cambia el nombre

3\. Edita `app.py` para implementar tu IA

4\. Súbelo como Hugging Face Space



\## Endpoint principal



\### `POST /run`



Envia un archivo (imagen/audio/video/texto)

y devuelve el resultado de la IA.
